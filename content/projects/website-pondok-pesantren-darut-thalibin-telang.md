Tentang Proyek

Website Pondok Pesantren Darut Thalibin Telang dikembangkan sebagai sarana informasi digital pondok. Website ini menyediakan informasi mengenai profil, pendidikan, kegiatan, organisasi, prestasi, berita, dan kontak pondok.

Selain sebagai media informasi, website ini juga dilengkapi Majmu' Digital untuk memudahkan akses ke bacaan yang digunakan dalam kegiatan sehari-hari.

Fitur Utama

* Halaman informasi pondok yang dapat diakses melalui desktop maupun perangkat seluler.
* Navigasi ke halaman pendidikan, kegiatan, berita, organisasi, prestasi, dan informasi lainnya.
* Majmu' Digital berisi surah pilihan, tahlil, dzikir dan doa seputar shalat, panduan shalat Dhuha, serta Ratib al-Haddad.
* Teks Arab, transliterasi Latin, dan terjemahan pada bacaan yang tersedia.- Pengaturan tampilan bacaan dan penanda bacaan yang tersimpan di perangkat pengguna.
* Penyimpanan lokal untuk data surah yang telah dimuat, sehingga dapat dibuka kembali tanpa koneksi.
* Pengelolaan konten bacaan melalui data JSON agar pengurus dapat memperbarui dan menyusun ulang isi.

Teknologi

Website dibangun menggunakan HTML, CSS, dan JavaScript tanpa framework. Proses build menggunakan Node.js, sedangkan deployment menggunakan Netlify. Data surah diambil melalui EQuran.id API dan disimpan sementara di perangkat untuk akses berikutnya.

Status Pengembangan

Proyek masih dikembangkan secara bertahap. Ratib al-Haddad sudah tersedia sebagai draf dan menunggu tashih pengurus, sementara konten Maulid Diba' masih dalam penyiapan.

Proyek kedepannya akan diintegrasikan dengan koperasi yang saat ini statusnya masih dalam proses pembentukan badan hukum
